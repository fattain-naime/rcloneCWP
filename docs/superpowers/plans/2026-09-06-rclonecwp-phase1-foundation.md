# rcloneCWP Phase 1 (Foundation) — CWP-Integration-First Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase 1 foundation of rcloneCWP such that the module *loads and renders inside the live CWP admin panel* (nginx cwpsrv, PHP 7.2.30), with a runtime-sourced DB layer, AES-256-GCM crypto, a hardened rclone wrapper, input validation, CSRF, and the destination base — all parsing on the CWP binary.

**Architecture:** Author everything in `/root/rcloneCWP/src/`; deploy to `/usr/local/cwpsrv/htdocs/resources/admin/modules/rcloneCWP/`. The module is `include()`d by the ionCube-encoded CWP dispatcher, which sets `$include_path` in its scope and (separately) gates admin login. rcloneCWP opens with the canonical `$include_path` guard **plus its own session check** (defense in depth — the encoded core's guard-vs-login ordering is unverifiable). All non-entry code lives *under* the module dir (already beneath `resources/`), so the nginx web root cannot serve `lib/`, `sql/`, `views/`, `cache/`, `logs/`. Credentials are never embedded: DB config is read from CWP's live `db_conn.php` at runtime, and encryption keys are generated by the installer into a root-only keyfile.

**Tech Stack:** PHP 7.2.30 (CWP binary `/usr/local/cwp/php71/bin/php` — NOT 8.3.31), PDO/MySQL/MariaDB 10.11.19, rclone v1.75.0 (`/usr/bin/rclone`), openssl AES-256-GCM, nginx cwpsrv 1.24.0, AlmaLinux 8.10.

## LENS / GLOBAL CONSTRAINTS (verified live on this host)

1. **PHP = `/usr/local/cwp/php71/bin/php` = 7.2.30.** No 8.3 syntax anywhere: NO typed properties, arrow fns, `match`, enums, `str_contains`, named args, `readonly`, constructor promotion, nullsafe `?->`. Available: `??`/`??=`, closures, anonymous classes, PDO, openssl. **Sodium is ABSENT** — all crypto via openssl. Lint everything with the 7.2 binary (the 8.3 CLI hides parse failures).
2. **DB credentials from `/usr/local/cwpsrv/htdocs/resources/admin/include/db_conn.php`** (`$db_host`, `$db_name="root_cwp"`, `$db_user="root"`, `$db_pass`). `/usr/local/cwp/.conf/mysql_db.cnf` DOES NOT EXIST. `/root/.my.cnf` corroborates the same password. `Database::getConfig()` parses `db_conn.php` at runtime.
3. **No `login` table exists** in `root_cwp` (only `backups, domains, nameserver, notifications, packages, settings, subdomains, user`). The guide's `isAdminAuthenticated()` → `SELECT * FROM login` WILL FATAL. The session check is **session-key-presence only** (`$_SESSION['lkey']` AND `$_SESSION['cp']`), layered on the dispatcher's own auth.
4. **Auth seam:** dispatcher `include()`s the module with `$include_path` set; canonical guard is `if(!isset($include_path)){echo 'invalid access';exit();}` (verified in `example.php`/`admin_messages.php`). Because core is ionCube, add an independent session check too.
5. **Module runs as ROOT** (php-fpm master = root). It owns its own CSRF tokens on every POST, its own Validator on all `$_GET`/`$_POST`, and `session_regenerate_id()` on auth changes.
6. **Web server = nginx cwpsrv 1.24.0.** No `.htaccess` anywhere — Apache deny is dead code. Keep `lib/ sql/ templates/ views/ cache/ logs/` under the module dir (beneath `resources/`). **Never** place `api/` or `cli/` under `/usr/local/cwpsrv/htdocs/admin` (the existing `/api` nginx location would serve them). Phase 1 does not create `api/`/`cli/`.
7. **rclone v1.75.0** at `/usr/bin/rclone`. `gdrive:` is already configured and usable for live tests. `rclone config show` prints cleartext secrets — **never log its output**; use `rclone config redacted`. No dedicated exit code for missing remote — parse stderr for `didn't find section in config file`. `rclone obscure` is reversible obfuscation, NOT encryption.
8. **Namespace `CWP\RcloneCWP`** (CLAUDE.md wins over guide's `CWP\RcloneModule`).
9. **Backup table = `rclone_backups`** (CLAUDE.md + rclone_ prefix wins over install.sql's `rcloneCWPs`).
10. **CWP updates `unzip -o` into `/usr/local/cwpsrv/htdocs`** — both the module dir and `3rdparty.php` can be wiped/reverted. Installer appends the menu entry idempotently and must be re-runnable to re-apply after updates.

```php
<?php
// rcloneCWP.php — main entry point (included by the CWP dispatcher)

// 1) Canonical CWP guard: the ONLY thing distinguishing "included by the dispatcher"
//    from "executed outside it". The dispatcher sets $include_path in its scope.
if (!isset($include_path)) {
    echo 'invalid access';
    exit();
}

// 2) Own config + autoloader
require_once __DIR__ . '/config.php';

// 3) Session (needed for CSRF + our own auth check). Start only if not already.

// 4) Independent admin-auth check (defense in depth — core is ionCube, guard-vs-login
//    ordering unverifiable). NOTE: there is NO `login` table in root_cwp, so we check
//    session-key presence only; the dispatcher already authenticated the admin.
function rcloneCwpIsAdmin()
{
    return isset($_SESSION['lkey'], $_SESSION['cp']);
}

// 5) Load core libs
require_once RCLONE_CWP_LIB . '/Database.php';
require_once RCLONE_CWP_LIB . '/Logger.php';
require_once RCLONE_CWP_LIB . '/Encryption.php';

    'dashboard' => RCLONE_CWP_VIEWS . '/dashboard.php',
];

    // Dispatcher should have blocked this; belt-and-suspenders.
    echo 'Access denied: CWP authentication required';

}

if (isset($routes[$action]) && is_file($routes[$action])) {
    require_once $routes[$action];

    require_once RCLONE_CWP_VIEWS . '/dashboard.php';
```

```php
<?php
namespace CWP\RcloneCWP;

use PDO;
use PDOException;

class Database
{
    private static $instance = null;
    private $pdo;

    private function __construct()
    {
        $cfg = $this->getConfig();
        $dsn = "mysql:host={$cfg['host']};dbname={$cfg['database']};charset={$cfg['charset']}";
        try {
            $this->pdo = new PDO($dsn, $cfg['username'], $cfg['password'], [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,   // do NOT weaken prepared statements
                PDO::MYSQL_ATTR_INIT_COMMAND => "SET NAMES {$cfg['charset']}",
            ]);
        } catch (PDOException $e) {
            throw new \Exception('Database connection failed: ' . $e->getMessage());
        }
    }

    public static function getInstance()
    {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance;
    }

    // Read CWP live credentials at runtime. mysql_db.cnf does not exist on this host.
    private function getConfig()
    {
        $host = 'localhost';
        $database = 'root_cwp';
        $username = 'root';
        $password = '';
        $charset = 'utf8mb4';

        if (is_file(CWP_DB_CONN)) {
            // db_conn.php defines $db_host/$db_name/$db_user/$db_pass (and $crypt_pwd).
            include CWP_DB_CONN;
            if (isset($db_host))   { $host = $db_host; }
            if (isset($db_name))   { $database = $db_name; }
            if (isset($db_user))   { $username = $db_user; }
            if (isset($db_pass))   { $password = $db_pass; }
        } elseif (is_file(CWP_MY_CNF)) {
            $ini = parse_ini_file(CWP_MY_CNF);
            if (isset($ini['password'])) { $password = $ini['password']; }
            if (isset($ini['user']))     { $username = $ini['user']; }
        } else {
            throw new \Exception('CWP database config not found (db_conn.php / .my.cnf)');
        }
        return compact('host', 'database', 'username', 'password', 'charset');
    }

    public function getConnection()
    {
        return $this->pdo;
    }

    // NEW — required by later-phase callers (isAdminAuthenticated, AuthMiddleware, RateLimitMiddleware)
    public function prepare($sql)
    {
        return $this->pdo->prepare($sql);
    }

    public function query($sql, $params = [])
    {
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($params);
        return $stmt;
    }

    public function fetch($sql, $params = [])
    {
        return $this->query($sql, $params)->fetch();
    }

    public function fetchAll($sql, $params = [])
    {
        return $this->query($sql, $params)->fetchAll();
    }

    public function insert($table, array $data)
    {
        $table = $this->ident($table);
        $cols = implode(', ', array_map([$this, 'ident'], array_keys($data)));
        $placeholders = implode(', ', array_fill(0, count($data), '?'));
        $sql = "INSERT INTO {$table} ({$cols}) VALUES ({$placeholders})";
        $this->query($sql, array_values($data));
        return $this->pdo->lastInsertId();
    }

    public function update($table, array $data, array $where)
    {
        $table = $this->ident($table);
        $set = implode(', ', array_map(function ($c) { return $this->ident($c) . ' = ?'; }, array_keys($data)));
        $w = implode(' AND ', array_map(function ($c) { return $this->ident($c) . ' = ?'; }, array_keys($where)));
        $sql = "UPDATE {$table} SET {$set} WHERE {$w}";
        return $this->query($sql, array_merge(array_values($data), array_values($where)))->rowCount();
    }

    public function delete($table, array $where)
    {
        $table = $this->ident($table);
        $w = implode(' AND ', array_map(function ($c) { return $this->ident($c) . ' = ?'; }, array_keys($where)));
        $sql = "DELETE FROM {$table} WHERE {$w}";
        return $this->query($sql, array_values($where))->rowCount();
    }

    // Identifiers (table/column/ORDER BY) can never be bound. Reject anything that could
    // break out of backticks. This is injection-safe for app-generated column names.
    // NOTE: user-supplied ORDER BY columns must ALSO be checked by the caller against a
    // per-table allowed-column list (see Task 9 note) — ident() alone cannot know intent.
    private function ident($name)
    {
        if (!preg_match('/^[A-Za-z_][A-Za-z0-9_]*$/', (string)$name)) {
            throw new \InvalidArgumentException("Disallowed identifier: {$name}");
        }
        return '`' . $name . '`';
    }
}
```

- [ ] **Step 1: Rewrite `src/sql/install.sql`** with the adjudicated fixes

Key changes vs shipped file:
  - `CREATE TABLE IF NOT EXISTS rclone_backups` (rename from `rcloneCWPs`); all FKs reference `rclone_backups`.
  - `rclone_backups.backup_type ENUM('full','incremental','selective')` (add `selective`).
  - `rclone_logs` gains `destination_id INT DEFAULT NULL` and `KEY idx_destination_id (destination_id)`, plus `KEY idx_created_at_id (created_at, id)` composite index; add `CONSTRAINT fk_log_destination FOREIGN KEY (destination_id) REFERENCES rclone_destinations(id) ON DELETE SET NULL`.
  - Seed API key: insert via a PHP-side `random_bytes(32)` value is not expressible in pure SQL, so the installer generates the key in PHP and injects it; the SQL file therefore seeds a **placeholder row the installer overwrites** OR the installer inserts the key row itself. Chosen approach (KISS, single source of truth): install.sql creates the table with NO seed row; `install.php` inserts the API key with a `random_bytes(32)` hex value and `permissions='["destinations:read","jobs:read","backups:read"]'` (explicit, no wildcard). The default notification row stays in SQL.
  - Keep all other 7 tables as shipped (they are correct).

## Task 4 — Encryption (AES-256-GCM via openssl)

**Files:**
- Create: `src/lib/Encryption.php`

**Interfaces:**
- Produces: `encrypt(string $plain): string`, `decrypt(string $packed): string|false`. Packed format = `base64( nonce(12) || tag(16) || ciphertext )`. Unique random nonce per call. Callers MUST check `decrypt() === false`. Key from `RCLONE_KEY_FILE` (created by installer). Static `ensureKey()` for installer use.

- [ ] **Step 1: Write `src/lib/Encryption.php`**

```php
<?php
namespace CWP\RcloneCWP;

class Encryption
{
    private $keyFile;
    private $key;

    public function __construct($keyFile = RCLONE_KEY_FILE)
    {
        $this->keyFile = $keyFile;
    }

    private function getKey()
    {
        if ($this->key !== null) { return $this->key; }
        if (!is_file($this->keyFile)) {
            throw new \Exception('Encryption keyfile missing: ' . $this->keyFile . ' — run install.php');
        }
        $raw = base64_decode(file_get_contents($this->keyFile), true);
        if ($raw === false || strlen($raw) !== 32) {
            throw new \Exception('Invalid encryption keyfile');
        }
        $this->key = $raw;
        return $this->key;
    }

    // Create the keyfile if missing (installer). 32 random bytes, 0600.
    public static function ensureKey($keyFile = RCLONE_KEY_FILE)
    {
        if (is_file($keyFile)) { return; }
        if (!is_dir(dirname($keyFile))) { mkdir(dirname($keyFile), 0700, true); }
        file_put_contents($keyFile, base64_encode(random_bytes(32)));
        chmod($keyFile, 0600);
    }

    public function encrypt($plain)
    {
        $key = $this->getKey();
        $nonce = random_bytes(12);              // GCM standard nonce size; unique per message
        $tag = '';
        $cipher = openssl_encrypt((string)$plain, 'aes-256-gcm', $key, OPENSSL_RAW_DATA, $nonce, $tag);
        if ($cipher === false) { throw new \Exception('openssl_encrypt failed'); }
        return base64_encode($nonce . $tag . $cipher);   // tag is 16 bytes for GCM
    }

    // Returns decrypted string, or false on ANY failure (tamper / wrong key / bad format).
    public function decrypt($packed)
    {
        $key = $this->getKey();
        $raw = base64_decode($packed, true);
        if ($raw === false || strlen($raw) < 28) { return false; }   // 12 nonce + 16 tag minimum
        $nonce = substr($raw, 0, 12);
        $tag = substr($raw, 12, 16);
        $cipher = substr($raw, 28);
        $out = openssl_decrypt($cipher, 'aes-256-gcm', $key, OPENSSL_RAW_DATA, $nonce, $tag);
        if ($out === false) { return false; }
        return $out;
    }
}
```

## Task 6 — Rclone wrapper (whitelist + sanitizer + traps)

**Files:**
- Create: `src/lib/Rclone.php`

**Interfaces:**
- Produces: `new Rclone($configPath=RCLONE_CONF, Logger $logger=null)`, `execute($command,$args=[],$options=[]): array{output,returnCode,success}`, convenience `copy/move/sync/ls/lsd/size/delete/rmdir/purge/mkdir/cat/checksum/version/obscure/testConnection`, `configRedacted()` (safe diagnostics), `parseMissingRemote($stderr): bool`.
- Security: command whitelist; **reject any token starting with `--` unless in the server-side fixed flag map**; denylist `--config/--password/--ask-password/-o`; reject remote/path names with a **leading `-`**; `escapeshellarg()` every token; `exec(..., 2>&1)`; **never log `config show` output** (use `configRedacted()`).

- [ ] **Step 1: Write `src/lib/Rclone.php`**

```php
<?php
namespace CWP\RcloneCWP;

class Rclone
{
    private $configPath;
    private $binaryPath;
    private $logger;

    // Server-side fixed flag map: only these --flags may appear, with controlled values.
    private static $allowedFlags = [
        '--transfers','--checkers','--buffer-size','--tpslimit','--tpslimit-burst',
        '--retries','--retries-sleep','--fast-list','--bwlimit','--config','--verbose',
        '--low-level-retries','--contimeout','--timeout','--stats','--no-check-certificate',
    ];

    private static $denyFlags = ['--password','--ask-password','-o','--config'];

    private static $allowedCommands = [
        'copy','move','sync','ls','lsd','lsl','size','delete','rmdir','rmdirs','purge',
        'mkdir','cat','checksum','version','config',
    ];

    public function __construct($configPath = RCLONE_CONF, Logger $logger = null)
    {
        $this->configPath = $configPath;
        $this->logger = $logger ?: new Logger('rclone');
        $this->binaryPath = $this->findBinary();
    }

    private function findBinary()
    {
        $paths = [RCLONE_BINARY, '/usr/local/bin/rclone', '/usr/local/sbin/rclone',
                  trim(@shell_exec('command -v rclone 2>/dev/null'))];
        foreach ($paths as $p) {
            if ($p && is_executable($p)) { return $p; }
        }
        throw new \Exception('rclone binary not found');
    }

    public function execute($command, array $args = [], array $options = [])
    {
        if (!in_array($command, self::$allowedCommands, true)) {
            throw new \Exception("Command not allowed: {$command}");
        }
        $cmd = [$this->binaryPath, $command];

        // Remote/path args: never allow a leading '-' (flag injection / arg confusion)
        foreach ($args as $a) {
            $a = (string)$a;
            if ($a === '' || $a[0] === '-') {
                throw new \Exception('Invalid argument (leading dash or empty): ' . var_export($a, true));
            }
            $cmd[] = escapeshellarg($a);
        }

        // Options: only server-approved flags; --config is forced to our path (no override)
        foreach ($options as $k => $v) {
            if (!in_array($k, self::$allowedFlags, true)) {
                throw new \Exception("Flag not allowed: {$k}");
            }
            if (in_array($k, self::$denyFlags, true)) {
                throw new \Exception("Flag denied: {$k}");
            }
            if ($v === '' || $v === false || $v === null) {
                $cmd[] = $k;
            } else {
                $cmd[] = $k . ' ' . escapeshellarg((string)$v);
            }
        }
        // Force our config file (no user --config override possible)
        $cmd[] = '--config ' . escapeshellarg($this->configPath);

        $final = implode(' ', $cmd) . ' 2>&1';
        $this->logger->debug('Executing rclone', ['cmd' => $final]);

        $output = [];
        $rc = 0;
        exec($final, $output, $rc);

        // NEVER log cleartext secrets: config show is blocked; redacted is safe.
        return ['output' => $output, 'returnCode' => $rc, 'success' => ($rc === 0)];
    }

    // --- convenience ---
    public function copy($s,$d,$o=[])    { return $this->execute('copy',[$s,$d],$o); }
    public function move($s,$d,$o=[])    { return $this->execute('move',[$s,$d],$o); }
    public function sync($s,$d,$o=[])    { return $this->execute('sync',[$s,$d],$o); }
    public function ls($r,$o=[])         { return $this->execute('ls',[$r],$o); }
    public function lsd($r,$o=[])        { return $this->execute('lsd',[$r],$o); }
    public function size($r,$o=[])       { return $this->execute('size',[$r],$o); }
    public function delete($r,$o=[])     { return $this->execute('delete',[$r],$o); }
    public function rmdir($r,$o=[])      { return $this->execute('rmdir',[$r],$o); }
    public function purge($r,$o=[])      { return $this->execute('purge',[$r],$o); }
    public function mkdir($r,$o=[])      { return $this->execute('mkdir',[$r],$o); }
    public function cat($r,$o=[])        { return $this->execute('cat',[$r],$o); }
    public function checksum($r,$h='sha256',$o=[]) { $o['--hash']=$h; return $this->execute('checksum',[$r],$o); }
    public function version()            { $r=$this->execute('version'); return $r; }
```

```php
<?php
namespace CWP\RcloneCWP;

class Validator
{
    public static function string($v, $maxLen = 255, $default = '')
    {
        if ($v === null) { return $default; }
        $v = trim((string)$v);
        $v = strip_tags($v);
        if ($maxLen > 0 && mb_strlen($v) > $maxLen) { $v = mb_substr($v, 0, $maxLen); }
        return $v;
    }

    public static function int($v, $min = null, $max = null, $default = 0)
    {
        if (!is_numeric($v)) { return $default; }
        $i = (int)$v;
        if ($min !== null && $i < $min) { return $min; }
        if ($max !== null && $i > $max) { return $max; }
        return $i;
    }

    public static function enum($v, array $allowed, $default = null)
    {
        $v = self::string($v, 64);
        if (in_array($v, $allowed, true)) { return $v; }
        return $default;
    }

    public static function bool($v)
    {
        return in_array($v, ['1','true','on','yes',true], true);
    }

    // rclone remote names: letters/digits/_/-, must not start with '-'
    public static function remoteName($v)
    {
        $v = self::string($v, 64);
        if ($v === '' || $v[0] === '-' || !preg_match('/^[A-Za-z0-9_][A-Za-z0-9_-]*$/', $v)) {
            return '';
        }
        return $v;
    }
}
```

```php
<?php
namespace CWP\RcloneCWP;

abstract class Destination
{
    public $type;
    public $name;
    public $icon;
    public $configFields = [];

    protected $rclone;
    protected $encryption;
    protected $logger;

    public function __construct(Logger $logger = null)
    {
        $this->logger = $logger ?: new Logger('destination');
        $this->rclone = new Rclone();
        $this->encryption = new Encryption();
    }

    abstract public function validateConfig($config);
    abstract public function testConnection($config);
    abstract public function buildRcloneConfig($config);
    abstract public function getStoragePath($config, $user);

    public function getConfigFields() { return $this->configFields; }

    public function encryptConfig($config)
    {
        $out = $config;
        $sensitive = ['password','secret','token','key','pass'];
        foreach ($out as $k => $v) {
            foreach ($sensitive as $s) {
                if (stripos($k, $s) !== false && $v !== '' && $v !== null) {
                    $out[$k] = $this->encryption->encrypt((string)$v);
                    break;
                }
            }
        }
        return $out;
    }

    public function decryptConfig($config)
    {
        $out = $config;
        $sensitive = ['password','secret','token','key','pass'];
        foreach ($out as $k => $v) {
            foreach ($sensitive as $s) {
                if (stripos($k, $s) !== false && $v !== '' && $v !== null) {
                    $dec = $this->encryption->decrypt((string)$v);
                    $out[$k] = ($dec === false) ? $v : $dec;
                    break;
                }
            }
        }
        return $out;
    }

    // Base implementation — Phase 2 callers (FTP/GoogleDrive) rely on these existing.
    // Strategy: the destination owns a TEMP rclone config (seeded by copying the live
    // /etc/rclone/rclone.conf so existing remotes like gdrive: remain usable), and routes
    // all rclone calls through an Rclone instance bound to that temp path. addTo appends a
    // section; removeFrom strips it; __destruct unlinks the file so secrets never linger.
    // The live /etc/rclone/rclone.conf is NEVER mutated.
    protected $tmpConfigPath = null;

    protected function ensureTmpConfig()
    {
        if ($this->tmpConfigPath === null) {
            $tmp = tempnam(sys_get_temp_dir(), 'rcwp_') . '.conf';
            if (is_file(RCLONE_CONF)) { copy(RCLONE_CONF, $tmp); } else { touch($tmp); }
            chmod($tmp, 0600);
            $this->tmpConfigPath = $tmp;
            $this->rclone = new Rclone($tmp, $this->logger);
        }
        return $this->tmpConfigPath;
    }

    public function __destruct()
    {
        if ($this->tmpConfigPath !== null && is_file($this->tmpConfigPath)) {
            @unlink($this->tmpConfigPath);
        }
    }

    public function addToRcloneConfig($name, $cfg)
    {
        $name = Validator::remoteName($name);
        if ($name === '') { throw new \Exception('Invalid remote name'); }
        $tmp = $this->ensureTmpConfig();
        $built = $this->buildRcloneConfig($cfg);
        $section = "[{$name}]\ntype = {$built['type']}\n";
        foreach ($built as $k => $v) {
            if ($k === 'type' || $v === '' || $v === null) { continue; }
            $section .= "{$k} = {$v}\n";
        }
        file_put_contents($tmp, $section, FILE_APPEND);
        return true;
    }

    public function removeFromRcloneConfig($name)
    {
        $name = Validator::remoteName($name);
        if ($name === '' || $this->tmpConfigPath === null || !is_file($this->tmpConfigPath)) {
            return false;
        }
        $lines = file($this->tmpConfigPath, FILE_IGNORE_NEW_LINES);
        $out = [];
        $skip = false;
        foreach ($lines as $ln) {
            if (preg_match('/^\[' . preg_quote($name, '/') . '\]\s*$/', $ln)) { $skip = true; continue; }
            if ($skip && $ln !== '' && $ln[0] === '[') { $skip = false; }
            if (!$skip) { $out[] = $ln; }
        }
        file_put_contents($this->tmpConfigPath, implode("\n", $out));
        return true;
    }
}
```

## Deviations From Docs (with reason)

1. **DB credential source** → read `/usr/local/cwpsrv/htdocs/resources/admin/include/db_conn.php` (+`/root/.my.cnf` fallback) at runtime, NOT `/usr/local/cwp/.conf/mysql_db.cnf`. Reason: the brief's file does not exist on this host (verified); `db_conn.php` is the live source. `Database::getConfig()` embeds nothing.
2. **Namespace** → `CWP\RcloneCWP` (CLAUDE.md) everywhere, NOT the guide's `CWP\RcloneModule`. Reason: CLAUDE.md is the committed project instruction; fixing now prevents propagation.
3. **Backup table** → `rclone_backups`, NOT `rcloneCWPs`. Reason: rclone_ prefix rule + mixed-case name breaks the convention; all queries target `rclone_backups`.
4. **`Database::prepare()` added.** Reason: 3 call sites (`isAdminAuthenticated`, `AuthMiddleware`, `RateLimitMiddleware`) require it; the guide's class spec omitted it.
5. **Logger is instance + injected** (refactoring the guide's static `Logger::` calls in `Rclone`/`Destination`). Reason: adjudicated — later-phase `BackupEngine`/`Hook`/`CLI` all use `$this->logger`.
6. **Seed API key** → `random_bytes(32)` hex, explicit non-wildcard `permissions`, inserted by `install.php` (not in pure SQL). Reason: shipped `REPLACE(UUID(),'-','')` + `['*']` is guessable and over-privileged.
7. **Schema extras** → `rclone_backups.backup_type` gains `'selective'`; `rclone_logs` gains `destination_id`, composite index `(created_at,id)`, and FKs. Reason: drift vs later tables / referential integrity per brief.
8. **Entry guard** → `$include_path` check (canonical, verified in `example.php`/`admin_messages.php`), NOT the guide's `defined('CWP_MODULE')` which does not prevent direct access.
9. **Session auth = key-presence only.** Reason: there is NO `login` table in `root_cwp` (verified), so the guide's `SELECT * FROM login` would fatal; the dispatcher already authenticated the admin, and we add defense-in-depth.
10. **Crypto via openssl** (AES-256-GCM), NOT sodium. Reason: sodium is absent on the CWP 7.2.30 binary (verified).
11. **Schema load via `mysql` CLI + temp `--defaults-extra-file`**, NOT PHP `explode(';')`. Reason: avoids the ';'-inside-string splitting defect and keeps credentials runtime-sourced.
12. **No `.htaccess` / Apache deny anywhere** (nginx cwpsrv). Non-entry files stay under the module dir (beneath `resources/`). `api/`/`cli/` are NOT created in Phase 1 (would be served by the `/api` nginx location if ever placed under `/admin`).
13. **Rclone wrapper hardening** → denylist `--config/--password/--ask-password/-o`, reject leading-`-` remote names and bare `--`, server-side fixed flag map; `config show` never logged (use `configRedacted`). Reason: prevents config-file redirection / credential exfil and secret leakage.
14. **PHP 7.2-only syntax enforced**; all files linted with `/usr/local/cwp/php71/bin/php`. Reason: the 8.3.31 CLI binary hides 7.2 parse failures — the trap called out in the brief.

## Risks / Notes for the executor

- **Re-apply after CWP update:** because `unzip -o` can revert the module dir and `3rdparty.php`, re-run `install.php` after any CWP admin update (it is idempotent for the menu entry and keyfile). Optionally add a cron entry later that runs `install.php` post-update.
- **AES-256-GCM is at-rest-only:** the keyfile is root-readable by the same uid that runs the module, so it protects off-box DB-dump leaks, not root/RCE. Per brief, treat as a checkbox.
- **`/backup` shares the root FS (42G free):** Phase 1 does no backups, but note this before Phase 3 writes large archives.
- **Session auth is key-presence only** (no `login` table) — acceptable defense-in-depth; the dispatcher performs the real login gate.
- **Do not add `api/` or `cli/` under the module's `htdocs/admin`** in later phases; the existing nginx `/api` location would serve them.
